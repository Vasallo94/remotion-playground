# Claude Code: usa /plan en segundos

**Objetivo:** Mostrar de forma muy breve qué hace el comando /plan y cómo se usa en Claude Code.
**Audiencia:** Personas que usan Claude Code por primera vez o quieren recordar el flujo de /plan.
**Tono:** Breve, claro y práctico. Sin voz ni música.

## Escenas

### 1. Qué vas a ver

- **Tipo:** intro
- **Duración:** 3s
- **Notas visuales:** Pantalla de apertura con el texto: '/plan = pide a Claude Code un plan antes de ejecutar cambios'. Estilo Betelgeuse, limpio y contrastado. Sin locución, sin música.

### 2. Ejecuta /plan

- **Tipo:** terminal
- **Duración:** 7s
- **Notas visuales:** Terminal realista con Claude Code. El usuario escribe /plan y aparece una respuesta breve con pasos propuestos antes de tocar el código. Resalta visualmente la idea de 'primero plan, luego acción'. Sin locución, sin música.

## Notas

Vídeo ultra breve de 2 escenas. No incluir voz ni música. Mantener el estilo Betelgeuse.
