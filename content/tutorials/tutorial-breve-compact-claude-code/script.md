# Tutorial breve de /compact en Claude Code

**Objetivo:** Explicar en menos de 30 segundos qué hace /compact, cuándo usarlo y cómo ejecutarlo en Claude Code.
**Audiencia:** Usuarios de Claude Code que quieren ahorrar contexto en sesiones largas.
**Tono:** claro, directo y práctico

## Escenas

### 1. Qué hace /compact

- **Tipo:** intro
- **Duración:** 4s
- **Voiceover:** Si tu sesión está muy larga, /compact resume el contexto y ayuda a seguir trabajando sin arrastrar tanto historial.
- **Notas visuales:** Pantalla limpia con el comando /compact destacado y una breve animación de resumen de contexto.

### 2. Ejecuta el comando

- **Tipo:** terminal
- **Duración:** 8s
- **Voiceover:** En Claude Code, escribe /compact y confirma. El asistente condensará la conversación actual para seguir desde ahí.
- **Notas visuales:** Terminal realista mostrando el comando /compact y una salida corta indicando que el contexto fue compactado.

### 3. Cuándo usarlo

- **Tipo:** callout
- **Duración:** 6s
- **Voiceover:** Úsalo antes de cambiar de tema, cuando notes que la conversación se vuelve pesada o si quieres limpiar ruido sin perder lo importante.
- **Notas visuales:** Callout con tres casos de uso: cambio de tema, sesión larga y limpieza de ruido.

### 4. Resumen

- **Tipo:** outro
- **Duración:** 4s
- **Voiceover:** En resumen: /compact mantiene la conversación útil y más ligera. Ideal para sesiones largas en Claude Code.
- **Notas visuales:** Cierre con el comando /compact y un mensaje de ‘sesión compactada’.

## Notas

Formato landscape. Sin audio avanzado. Mantener ejemplo simple y visuales tipo terminal.
